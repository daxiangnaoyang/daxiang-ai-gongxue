不是学完一堆名词，而是带走三样东西。

每条路线都从一项具体工作开始，最后落到能交付、能复用的结果。

    一份成果

从你的起点进入

先找到卡住的那一步。

小白、职场人、创作者和想搭 Agent 的人，都从自己的任务开始。

    AI 入门

    看清大模型、提示词、Agent 与工具关系。

    职场提效

    总结、方案、表格、纪要，更快更稳。

    内容创作

    选题 → 素材 → 初稿 → 审校 → 分发。

  • 04 · 按步执行

    个人 Agent

    读文件、用工具、按步骤执行。
